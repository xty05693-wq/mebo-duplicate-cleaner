# Mebo Duplicate Cleaner

> Находит **настоящие** копии файлов по содержимому (SHA-256), а не по названию, фильтрует поиск по размеру, типу и дате, а лишнее отправляет в корзину Windows.

Один файл `MeboDuplicateCleaner.exe`: без установки, без .NET / Electron, без служб, автозагрузки и телеметрии.
Чистый **C++17 + WinAPI + GDI+**, используются только системные API (`bcrypt`, `shell32`, `gdiplus`, `dwmapi`, `comdlg32`).

## ✨ Возможности

- **Совпадение по содержимому.** Сначала группировка по размеру, затем SHA-256 каждого файла этой группы: `отчёт (2).pdf`, `копия отчёта.pdf` и `final_final.pdf` будут найдены, даже если имена и даты различаются.
- **Несколько папок за пуск.** В поле пути папки разделяются вертикальной чертой: `D:\Фото|D:\Архив|E:\Дистрибутивы`. Кнопка «Обзор…» не заменяет выбор, а добавляет к нему; вложенные одна в другую папки не обходятся дважды.
- **Пропуск служебного.** По умолчанию не ходит в скрытые и системные каталоги, `$RECYCLE.BIN`, `System Volume Information`, `WinSxS`, `node_modules`, `.git`, `__pycache__`, и не считает `desktop.ini` / `Thumbs.db` дубликатами. Одной галочкой в меню «Фильтры» это выключается.
- **Фильтры.** Минимальный размер (от 100 КБ до 1 ГБ), тип (картинки / документы / архивы / музыка и видео / код и текст), дата изменения (за 7 и 30 дней, за год, старше года). Фильтры применяются и к уже найденному: список пересобирается мгновенно, исходный результат не теряется.
- **Оригинал не удаляется.** В каждой группе один файл помечен `ОРИГИНАЛ`, остальные копии автоматически отмечены галочками — но отметить/снять можно что угодно, вручную или по группе.
- **Правила выбора оригинала.** Самый старый (по умолчанию), самый новый, «без `(1)` и `копия` в имени», самый короткий путь, первый найденный. Плюс `ПКМ` → «Сделать оригиналом» для конкретной группы.
- **Только корзина.** Удаление идёт через `SHFileOperationW` с `FOF_ALLOWUNDO`: копии можно восстановить из корзины Windows. Перед удалением — подтверждение с числом файлов и освобождаемым местом.
- **Ничего не меняется во время поиска.** Сканирование, фильтры и хэширование только читают; запись (отчёт) и удаление происходят исключительно по кнопке.
- **Экспорт списка.** `Ctrl+S` — CSV с разделителем `;` и UTF-8 BOM (сразу открывается в Excel), `Ctrl+Shift+S` — читаемый TXT-отчёт с хэшами групп; тот же отчёт можно скопировать в буфер обмена.
- **Фоновый поиск.** Обход и хэширование живут в отдельном потоке: интерфейс не подвисает, прогресс, скорость (файлов/с) и оценка оставшегося времени видны в статус-строке, кнопка «Отмена» прерывает работу.
- **Быстрый выбор папок.** Кнопки «Загрузки / Документы / Рабочий стол / Изображения» берутся из known folders системы: один клик, и путь уже в поле.
- **Тёмный интерфейс на GDI+.** Карточки групп, плавная прокрутка, анимации, контекстное меню, KPI-подвал (группы · файлы · освободится · помечено), группы отсортированы по выгоде — сверху то, что освободит больше всего.
- **DPI 100–300 %** (Per-Monitor V2), тёмная шапка окна, скруглённые углы на Windows 11.

## 📥 Запуск

**Из релиза:** скачайте `MeboDuplicateCleaner.exe` со страницы [Releases](releases/latest), распакуйте в любую папку, запустите двойным кликом. Установка не требуется — программа ничего не пишет в реестр.

**Требования:** Windows 10 (1903+) или Windows 11, x64. Дополнительные DLL и рантаймы не нужны — только системные библиотеки Windows.

**Из командной строки** — указанные папки сканируются сразу:

```powershell
# открыть программу и сразу искать дубликаты в папке
.\MeboDuplicateCleaner.exe "D:\Архив\Фото"

# несколько папок — аргументами или через |
.\MeboDuplicateCleaner.exe "D:\Фото" "E:\Дистрибутивы"
.\MeboDuplicateCleaner.exe "D:\Фото|E:\Дистрибутивы"

# например, из контекста папки или планировщика
Start-Process .\MeboDuplicateCleaner.exe -ArgumentList '"C:\Users\me\Downloads"'
```

## 🔨 Сборка из исходников

Исходник один — `native/MeboDuplicateCleaner.cpp`.

**MinGW-w64 / TDM-GCC:**

```bat
g++ -O2 -std=c++17 -municode -mwindows MeboDuplicateCleaner.cpp ^
  -o MeboDuplicateCleaner.exe ^
  -ldwmapi -lbcrypt -lole32 -luuid -lshell32 -lshlwapi -lcomdlg32 ^
  -lgdi32 -luser32 -lgdiplus
```

**MSVC (x64 Native Tools Command Prompt):**

```bat
cl /O2 /EHsc /DUNICODE /D_UNICODE MeboDuplicateCleaner.cpp ^
   /Fe:MeboDuplicateCleaner.exe user32.lib gdi32.lib dwmapi.lib ^
   shell32.lib shlwapi.lib ole32.lib bcrypt.lib gdiplus.lib comdlg32.lib
```

## ⚙️ Как это работает

1. **Обход** выбранных папок: итеративный обход в глубину (стек вместо рекурсии) на `FindFirstFileW`/`FindNextFileW`, по каждой указанной папке отдельно.
2. На ходу отсеивается лишнее: пустые файлы (0 байт), `desktop.ini`/`Thumbs.db`, симлинки и junction'ы (reparse points — именно они дают петли вроде `C:\Users\...\Application Data`), скрытые и служебные каталоги, а также файлы, не прошедшие фильтр по размеру, типу и дате. В статус-строке видно, сколько файлов отсеяно.
3. Оставшиеся файлы раскладываются **по размеру** (сортировка вместо map — меньше аллокаций), в память для хэширования попадают только группы из двух и более файлов.
4. У каждого кандидата вычисляется **SHA-256** (BCrypt, потоковое чтение по 64 КБ, `FILE_FLAG_SEQUENTIAL_SCAN`) — файл целиком в память не грузится. Совпавшие хэши = одна группа дубликатов.
5. Группы сортируются **по освобождаемому месту** (большие сверху), внутри каждой по правилу выбирается оригинал, остальные копии помечаются галочками. Ручной выбор («Сделать оригиналом») переопределяет правило до следующего сканирования.
6. Изменения фильтров применяются к уже найденному: сырой результат лежит отдельно, поэтому список пересобирается мгновенно и ничего не нужно сканировать заново.
7. Удаление — пакетный `SHFileOperationW` в корзину, после чего список пересобирается, а удалённые файлы вычёркиваются из сырого результата.

> Хэширование — это SHA-256, а не побайтовое сравнение, так что теоретическую коллизию программа не перепроверяет. Для пользовательских файлов это всё равно надёжнее поиска по имени и размеру, который путает `отчёт (1).pdf` с другим содержимым и настоящий дубликат с другим именем.

## 🚫 Чего пока нет (честно)

- Собственного списка исключений: есть только встроенный стоп-лист (`$RECYCLE.BIN`, `node_modules`, `.git`, скрытые и системные папки) и галочка «пропускать», а «кроме D:\Backup» придётся вычитать руками.
- Произвольной маски расширений (например, «только `.pdf` и `.docx`») — есть шесть готовых наборов типов.
- Сохранения сессии: найденное живёт в памяти окна, при закрытии теряется (для записи есть экспорт).
- Кэша хэшей: повторный поиск по той же папке считает SHA-256 заново.
- Настроек в реестре/файле: параметры фильтра живут только до закрытия программы.
- Поиск похожих, а не идентичных файлов (переснятые фото, ресейвы) — это отдельная задача и другой алгоритм.

## 🎛 Фильтры, правила и экспорт

Кнопка **«Фильтры»** (или `Ctrl`+`F`) открывает меню с четырьмя группами настроек:

| Раздел | Что делает |
|---|---|
| Минимальный размер | от 100 КБ до 1 ГБ — мелочь вроде `favicon.ico` не засоряет список |
| Тип файлов | картинки, документы, архивы, музыка и видео, код и текст |
| Дата изменения | за 7 / 30 дней, за год, старше года — по времени записи на диск |
| Что считать оригиналом | самый старый (по умолчанию), самый новый, без «(1)» и «копия» в имени, самый короткий путь, первый найденный |

Плюс переключатель «Пропускать служебные и скрытые папки» и «Сбросить фильтры и правила».

Фильтры ничего не портят: сырой результат поиска хранится отдельно, поэтому список пересобирается
при смене фильтра мгновенно, без нового сканирования, а снятие фильтра возвращает всё как было.
Отметки, которые вы ставили руками, при пересборке сохраняются; «Сделать оригиналом» из `ПКМ`
переопределяет правило для конкретной группы до следующего поиска.

**Экспорт.** `Ctrl`+`S` — CSV, `Ctrl`+`Shift`+`S` — TXT; то же самое в `ПКМ` по пустой области и внизу
меню «Фильтры». CSV — строка на файл: группа, размер, число копий, освобождаемое место, SHA-256,
роль (оригинал/дубликат), отмечен ли, дата изменения, имя, папка, полный путь. Разделитель `;`,
кодировка UTF-8 с BOM — Excel открывает файл без танцев с мастером импорта. TXT — читаемый отчёт
с шапкой (папки, фильтры, правило, итоги) и блоками по группам; тот же отчёт можно скопировать в буфер.

## 🔒 Приватность

- Ни одного сетевого запроса: в коде нет WinINet, WinHTTP и сокетов — можно проверить монитор брандмауэра.
- Никакой телеметрии, идентификаторов, cookies, «улучшения продукта».
- Пути и имена файлов никуда не отправляются и не сохраняются: результаты живут только в памяти окна до закрытия.
- Файл отчёта появляется только там, где вы сами его выбрали в диалоге сохранения: временных файлов рядом с вашими программа не создаёт.
- Программа не устанавливается: не трогает реестр, не создаёт служб и задач планировщика.

## 🐛 Нашли баг?

Откройте [Issue](issues/new) и укажите:

1. версию Windows (например, `Windows 11 23H2`) и масштаб экрана (100 / 125 / 150 %);
2. какие папки сканировали и какие фильтры были включены (видно в меню «Фильтры» и в чипсе строки статуса);
3. что произошло вместо ожидаемого (текст из статус-строки, скриншот, CSV-отчёт);
4. версию программы — она показана в шапке окна и в меню «О программе» (`ПКМ` по пустой области).

Особенно полезны случаи, когда дубликат **не** найден или найден ложно: приложите `Get-FileHash -Algorithm SHA256` для пары файлов.
